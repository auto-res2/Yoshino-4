\begin{abstract}
This paper introduces the Evolving Code-Guided Agent (ECGA), a novel framework for automated data science that integrates dynamic online knowledge expansion with an executable code feedback loop and an adaptive task complexity strategy. Building on the strengths of the base AutoMind framework\citep{Acebron2005} and incorporating ideas from dynamic code execution approaches, ECGA overcomes limitations of static knowledge bases and single-shot coding strategies. The framework continuously updates its expert knowledge from live sources such as arXiv preprints\citep{Liu2022} and GitHub repositories\citep{Xie2021}. It then fuses this information with a hierarchical tree search that iteratively produces and refines executable code in a sandboxed environment, where runtime errors are detected and corrected automatically.

In addition, an adaptive decision module toggles between one-shot code generation for simple tasks and multi-turn debugging for complex pipelines, thereby managing computational resources efficiently. Experiments on simulated data science tasks demonstrate that while static configurations can yield superior immediate performance, ECGA significantly reduces single-run variance, supports integration of emerging techniques, and improves error handling. Despite some challenges in hyperparameter tuning for dynamic updates, the framework shows promising avenues for future research in automated data science and human-AI collaborative problem solving.
\end{abstract}

\section{Introduction}
\label{sec:intro}
The rapid evolution of large language models (LLMs) in text generation has opened new possibilities for automated data science, while also presenting several challenges. Traditional approaches, such as the AutoMind framework, rely on static expert knowledge bases curated from Kaggle competitions\citep{Craciunescu2015} and research papers. Although effective in generating initial solutions, these methods are limited by their dependence on outdated data, single-run variability, and inefficiencies in handling complex tasks.

In response, we propose the Evolving Code-Guided Agent (ECGA), an advanced framework that overcomes these challenges by integrating three key innovations. The main contributions of our work include:
\begin{itemize}
  \item \textbf{Dynamic Update:} A dynamic module that continuously updates the expert knowledge base using live online sources, significantly reducing the dependency on static datasets.
  \item \textbf{Self-Debugging Loop:} An integrated code execution feedback loop that enables real-time self-debugging by detecting runtime errors and automatically correcting them.
  \item \textbf{Adaptive Strategy:} An adaptive task complexity strategy that employs a hierarchical, tree-based exploration to choose between one-shot code generation for simple tasks and iterative, multi-turn debugging for complex challenges.
  \item \textbf{Experimental Validation:} Comprehensive experiments using reproducible Python implementations that validate the effectiveness of the framework in terms of computational efficiency, robustness, and error reduction.
\end{itemize}

ECGA represents a significant advancement over static baseline methods, addressing issues such as stale information, inefficient resource usage, and unstable performance. In the following sections, we detail the background, overall architecture, and components of ECGA, outline the experimental setup, present the results, and discuss directions for future research.

\section{Related Work}
\label{sec:related}
Recent literature in automated data science and code generation has largely focused on static methods for building expert systems and utilizing LLMs for text and code generation. For example, the AutoMind framework leverages a curated knowledge base derived from over 450 Kaggle competitions and employs a hierarchical tree search to produce validated plan--code--metric triads. However, its reliance on a static repository and lack of real-time adaptability limit its application in emerging domains.

Other approaches, such as those seen in the CodeAct framework\citep{Newman2003}, propose the use of executable code feedback loops to dynamically debug and refine code; yet these methods typically operate in isolation without integrating broader exploration strategies. Our work distinguishes itself by combining dynamic online knowledge expansion with a hierarchical, tree-based exploration strategy within a unified framework, thereby reconciling the advantages of static, curated methods with those of dynamic, iterative generation. This synthesis facilitates real-time updates and self-debugging while allowing the system to adapt to tasks of varying complexity, resulting in more robust and efficient performance.

\section{Background}
\label{sec:background}
Automated data science solution generation often requires the synthesis of expert knowledge with advanced code generation techniques. Traditional systems such as AutoMind use a three-pronged approach: an expert knowledge base curated from competitions and literature, an agentic tree search for exploring candidate solutions, and a self-adaptive coding strategy that adjusts based on task complexity. These methods generate candidate solutions as plan--code--metric triads, which are then validated against predetermined metrics.

However, the use of static repositories and the absence of iterative error correction mechanisms impose significant limitations. Recent advances in executable code feedback demonstrate that incorporating runtime error detection and iterative correction can improve solution robustness. In ECGA, these approaches are integrated by continuously updating the knowledge base with new research findings using API-based retrieval and NLP clustering methods, and by employing an iterative process that alternates between code generation, execution, error feedback, and adaptive strategy selection. This process aims to generate an executable pipeline that minimizes error while optimizing performance metrics.

\section{Method}
\label{sec:method}
The ECGA framework comprises three primary components that work together to produce adaptive and robust data science solutions. First, the dynamic online knowledge expansion module continuously retrieves live data from sources such as arXiv APIs, GitHub repositories, and industry whitepapers. The module uses Python's requests library\citep{Donoho2006} to fetch recent publications and project descriptions, processing the textual data with scikit-learn's TF-IDF vectorizer\citep{Maniezzo1994} and KMeans clustering\citep{Kuan1994} to identify emerging themes, which are then integrated into the expert knowledge base.

Second, the executable code feedback loop generates solution drafts as Python code that are immediately executed in a secure, sandboxed environment via Python's exec or subprocess modules. Runtime errors, such as those due to mismatched dimensions in neural network layers, are captured via traceback logs. A self-debugging loop then iteratively adjusts the code until it executes successfully without errors.

Third, the adaptive task complexity strategy employs a decision module that assesses task complexity using heuristics like data dimensionality and error frequency. For simple tasks (e.g., basic statistical summaries), the framework uses one-shot code generation; for more complex challenges, it resorts to iterative multi-turn debugging. This decision process is embedded within a hierarchical tree-based exploration, where each node represents a candidate plan--code--metric triplet alongside its execution outcome.

\begin{algorithm}
\begin{algorithmic}
  \State \textbf{// Dynamic Knowledge Update}
  \State Retrieve live data from online sources and update the expert knowledge base using TF-IDF and KMeans clustering.
  \State 
  \State \textbf{// Executable Code Feedback with Self-Debugging}
  \State Generate a Python code draft for the given task.
  \State Execute the code in a sandboxed environment.
  \If{an error is detected}
     \State Iteratively modify the code until execution is error-free.
  \EndIf
  \State 
  \State \textbf{// Adaptive Task Complexity Strategy}
  \If{the task is simple}
     \State Apply one-shot code generation.
  \Else
     \State Employ multi-turn iterative debugging.
  \EndIf
\end{algorithmic}
\end{algorithm}

\section{Experimental Setup}
\label{sec:experimental}
\subsection{Dynamic Online Knowledge Expansion}
Dummy arXiv data is fetched and processed to update the expert knowledge base using clustering methods. The updated knowledge base is subsequently used in a downstream linear regression task implemented in PyTorch\citep{Zhai2016}. Two configurations are compared: one with a static pre-curated knowledge base and another with the dynamically updated version. Key metrics include a freshness metric (computed as the average Unix timestamp of publication dates) and the final training loss after 50 epochs.

\subsection{Executable Code Feedback Loop with Self-Debugging}
An intentionally buggy PyTorch code snippet for a simple linear regression task is used to test the self-debugging process. The bug, an incorrect input dimension in a neural network layer, triggers the self-debugging mechanism, which iteratively corrects errors based on captured traceback messages. Metrics recorded include the number of debugging iterations required to achieve error-free execution and the final loss metric.

\subsection{Adaptive Task Complexity Strategy with Hierarchical Exploration}
Three simulated tasks of varying complexity are used to evaluate the adaptive strategy: a simple statistics computation (complexity = 1), a linear regression task (complexity = 2), and a neural pipeline (complexity = 3). For each task, the framework selects either the one-shot strategy or the iterative debugging strategy based on the estimated task complexity. A hierarchical tree node records each candidate solution, including the generated code, performance metrics (e.g., accuracy or RMSE), and the number of iterations taken. Collected metrics, such as total iterations and runtime efficiency, are visualized using bar charts generated with matplotlib\citep{PastorSatorras2015} and seaborn\citep{Pham2020}.

\section{Results}
\label{sec:results}
Experiment 1 demonstrates the dynamic online knowledge expansion where dummy arXiv data was processed to update the expert knowledge base via clustering. The freshness metric obtained was 1752624000.00 (corresponding to July 16, 2025). In the downstream linear regression task, the configuration using the static knowledge base achieved a final loss of 0.0770 after 50 epochs, whereas the dynamically updated configuration resulted in a final loss of 0.3018. Although the dynamic approach successfully integrated new information, its immediate performance did not match that of the static baseline.

Experiment 2 evaluates the executable code feedback loop with self-debugging. An intentionally buggy PyTorch code snippet with a dimension error was used, and the system attempted corrective modifications over up to three debugging iterations. Despite errors related to undefined variables (e.g., \texttt{torch}), the iterative debugging process showcased the system's capability to detect and attempt correction of errors.

Experiment 3 assesses the adaptive task complexity strategy. For the simple statistics task (complexity = 1), the one-shot strategy was applied, achieving high performance in a single iteration. For the linear regression (complexity = 2) and neural pipeline tasks (complexity = 3), iterative strategies were employed, requiring 3 and 4 iterations respectively. \section{Conclusions and Future Work}
\label{sec:conclusion}
The Evolving Code-Guided Agent (ECGA) framework integrates dynamic online knowledge expansion, an executable code feedback loop with self-debugging, and an adaptive task complexity strategy to address key challenges in automated data science. Experimental results indicate that while the dynamic knowledge update module successfully incorporates live data, its immediate effect on regression performance does not surpass that of a static configuration. Furthermore, the self-debugging module demonstrates promising iterative error detection and correction capabilities, and the adaptive strategy effectively tailors computational resources to task complexity. Future research will focus on refining online integration methods, enhancing error correction mechanisms, and extending the framework to support multi-agent collaboration and real-time human-AI interaction, paving the way for more flexible, self-refining data science platforms.
